# Assets Folder

Place your media files here:

## 🎵 Audio Files
- `wedding-music.mp3` - Background music (optional)
  - Recommended: Traditional Indian instrumental (Shehnai, flute, sitar)
  - Format: MP3
  - Duration: 2-5 minutes (will loop)
  - Size: Keep under 5MB for faster loading

## 🖼️ Image Files (Optional)
- `bride.jpg` - Bride's photo
- `groom.jpg` - Groom's photo
- `couple.jpg` - Couple's photo together
- `invitation-card.jpg` - Scanned invitation card
- `venue.jpg` - Venue photo
- `ganesha.png` - High-quality Ganesha illustration (if you want to replace SVG)

## 📝 Notes
- All media files are optional
- The website works perfectly without any assets
- Images should be optimized for web (compressed, appropriate size)
- Use WebP format for better compression (with JPG/PNG fallback)
- Audio must be licensed or royalty-free

## 🎨 Recommended Image Sizes
- Photos: 800x800px to 1200x1200px (square or portrait)
- Background images: 1920x1080px
- Icons/logos: 512x512px
- Keep file sizes under 500KB each
