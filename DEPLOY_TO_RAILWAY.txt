🚀 DEPLOYMENT METHODS
================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
METHOD 1: DEPLOY FROM GITHUB (RECOMMENDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: CREATE GITHUB REPOSITORY
---------------------------------
1. Go to: https://github.com/new
2. Sign up/Login if needed
3. Repository name: wedding-invitation
4. Select: Public
5. Click: "Create repository"

STEP 2: UPLOAD YOUR FILES TO GITHUB
------------------------------------
1. On the repository page, click: "uploading an existing file"
2. Open this folder: wedding-deploy
3. Select ALL files:
   - index.html
   - styles.css
   - script.js
   - server.js
   - package.json
   - .gitignore
   - assets (folder)
4. DRAG them onto GitHub
5. Add commit message: "Initial commit"
6. Click: "Commit changes"
7. Wait for upload to complete

STEP 3: DEPLOY TO RAILWAY
--------------------------
1. Go to: https://railway.app
2. Click: "Start a New Project"
3. Click: "Deploy from GitHub repo"
4. Sign in with GitHub (authorize Railway)
5. Select your repository: wedding-invitation
6. Click: "Deploy Now"
7. Wait 2-3 minutes for deployment
8. Click: "Generate Domain" (or "Settings" → "Domains" → "Generate Domain")
9. DONE! Your site: https://wedding-invitation-production.up.railway.app

METHOD 2: DEPLOY WITH RAILWAY CLI (ADVANCED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: INSTALL RAILWAY CLI
----------------------------
Open PowerShell and run:
npm install -g @railway/cli

STEP 2: LOGIN TO RAILWAY
-------------------------
railway login

(Opens browser for authentication)

STEP 3: NAVIGATE TO FOLDER
---------------------------
cd C:\Users\DELL\OneDrive\Desktop\wedding\wedding-deploy

STEP 4: INITIALIZE AND DEPLOY
------------------------------
railway init
railway up

Your site will be live in 2 minutes!

STEP 5: GET YOUR URL
--------------------
railway domain

Or go to dashboard: https://railway.app/dashboard
